Principais formatações

Negrito / Destaque

Nesta frase temos um termo em negrito usando a tag b. (não semântica)

Nesta frase temos um termo em destaque usando a tag STRONG (semântica).

Itálico / Ênfase

Nesta frase, temos o termo itálico usando a tag I (Não semântica)

Nesta frase, temos o termo itálico usando a tag EM (semântica).

Texto marcado

Podemos criar tambem um texto marcado usando a tag MARK.

Texto Grande e pequeno

Estamos criando um texto grande com a tag BIG e um texto pequeno neste parágrafo com a tag SMALL.

Testo deletado

Podemos marcar um texto como excluído para indicar que ele deve ser lido mas não considerado com a tag DEL.

Testo inserido

Podemos marcar um texto como inserido para dar uma ênfase e indicar que ele foi adicionado depois com a tag INS. (Semântica)

Existe também o sublinhado que usa a tag U (Não semântica).

Texto sobrescrito

Para inserir coisas do tipo x20+3 Usando a tag SUP

Texto subescrito

Para inserir coisas do tipo H2O Usando a tag SUB
